# Yuntu 项目分析

## 1. 中文简介
Yuntu 是一款 AI 旅行规划引擎，支持确定性的路线调度与经过验证的兴趣点（POI）数据，并基于事实生成内容，确保旅行计划的准确性与可靠性。

## 2. 核心功能
- **确定性路线调度**：基于算法生成最优旅行路线，避免随机性
- **验证兴趣点（POI）库**：提供经过核实和筛选的景点、餐饮等推荐
- **事实驱动的 LLM 生成**：利用大语言模型生成内容，同时确保信息真实可信
- **前后端分离架构**：后端采用 FastAPI，前端使用 React 构建
- **结构化数据存储**：使用 PostgreSQL 管理旅行数据和用户信息

## 3. 适用场景
- **个人旅行规划**：用户输入目的地和时间，自动生成详细行程
- **旅行社辅助工具**：帮助旅行社快速生成定制化旅行方案
- **旅游信息聚合平台**：整合景点、路线、攻略等一站式服务
- **智能客服场景**：为游客提供基于事实的旅行问答服务

## 4. 技术亮点
- 结合传统算法与 LLM，兼顾路线优化的确定性和内容生成的灵活性
- 通过验证 POI 数据减少大模型"幻觉"问题，提升信息可信度
- 技术栈现代化，FastAPI + React + PostgreSQL 组合适合快速迭代开发

## LlamaFactory 项目分析

### 1. 中文简介
LlamaFactory 是一个统一且高效的大模型微调框架，支持 100+ 种大语言模型（LLM）和视觉语言模型（VLM）的微调。该项目由 ACL 2024 会议收录，旨在为研究者与开发者提供一站式模型微调解决方案。

### 2. 核心功能
- 支持 100+ 主流大语言模型和视觉语言模型的统一微调
- 提供 LoRA、QLoRA、全参数微调等多种高效微调策略
- 集成 RLHF（基于人类反馈的强化学习）训练能力
- 支持量化技术（如 4bit/8bit 量化），降低显存占用
- 内置指令微调（Instruction Tuning）与 Agent 构建功能

### 3. 适用场景
- **企业级模型定制**：基于 Llama、Qwen、DeepSeek 等开源模型进行领域适配
- **学术研究**：快速验证不同微调方法（LoRA/QLoRA/RLHF）的效果
- **多模态应用开发**：对视觉语言模型进行微调以支持图文理解任务
- **资源受限环境**：利用量化微调技术在低显存设备上训练大模型

### 4. 技术亮点
- **统一架构**：一套代码适配 100+ 模型，无需为每个模型单独编写适配脚本
- **高效显存优化**：支持 QLoRA 与多精度量化，大幅降低训练成本
- **完整训练链路**：从指令微调到 RLHF 对齐，覆盖大模型训练全流程
- **活跃的社区生态**：7.4万+星标，持续支持最新模型（如 Llama 3、Gemma、DeepSeek 等）

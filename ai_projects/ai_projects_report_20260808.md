# LlamaFactory 项目分析

## 1. 中文简介

LlamaFactory 是一个统一且高效的大语言模型（LLM）和视觉语言模型（VLM）微调框架，支持100多种主流模型。该项目已在 ACL 2024 会议上发表，为研究者和企业提供了一站式模型微调解决方案。

## 2. 核心功能

- **多模型支持**：兼容 Llama、Qwen、DeepSeek、Gemma、GPT 等100多种大语言模型和视觉语言模型
- **高效微调方法**：支持 LoRA、QLoRA、全参数微调等多种参数高效微调（PEFT）技术
- **量化训练**：提供 INT4/INT8 量化支持，降低显存占用，使消费级显卡也能训练大模型
- **RLHF 对齐**：内置奖励模型和强化学习人类反馈（RLHF）训练流程
- **指令微调**：支持标准化指令微调，提升模型任务遵循能力

## 3. 适用场景

- **学术研究**：快速复现和验证大模型微调算法，支持 ACL 等顶会论文复现
- **企业应用**：基于开源模型微调垂直领域专用模型，降低定制化成本
- **个人开发者**：在有限显存条件下微调大模型，实现本地部署和私有化应用
- **多模态任务**：对视觉语言模型进行微调，支持图文理解等复杂任务

## 4. 技术亮点

- **统一架构**：一个框架覆盖100+模型，无需切换工具链
- **Mixture-of-Experts（MoE）支持**：兼容稀疏专家混合架构模型的高效微调
- **Agent 能力增强**：支持工具调用和智能体（Agent）场景的微调优化
- **ACL 2024 认可**：经学术界同行评审验证，具备研究级可靠性
- **高社区认可度**：73912+ 星标，是 GitHub 上最受欢迎的大模型微调项目之一

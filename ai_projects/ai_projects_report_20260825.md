## 项目分析：deepseek-v4-flash-vision-video-rag

---

### 1. 中文简介

该项目基于DeepSeek视觉大模型，实现视频理解与问答（Video RAG）功能。它能先对视频按时间轴抽帧建立索引，再针对用户问题执行粗筛、精排、深读，最终给出带时间戳的精准答案和可播放片段。

---

### 2. 核心功能

- **视频抽帧索引**：按时间轴一次性提取关键帧并建立检索索引。
- **三层问答流程**：本地粗筛 → 视觉精排 → 深度阅读，逐级精准定位答案。
- **时间戳引用**：答案附带 `[MM:SS]` 格式的时间定位，方便用户快速跳转。
- **自动生成预览页**：输出自包含 HTML 页面，内嵌可播放片段与关键帧，双击即可在浏览器中查看。

---

### 3. 适用场景

- **教学视频检索**：快速定位课程中某个知识点的讲解片段。
- **监控/安防视频分析**：从长时间监控录像中精准提取事件发生时段。
- **会议/讲座视频问答**：对长视频内容进行语义检索，快速获取关键发言段落。
- **影视素材剪辑辅助**：帮助剪辑师快速找到特定画面或场景。

---

### 4. 技术亮点

- 采用 **Video RAG（视频检索增强生成）** 架构，将传统向量检索与视觉理解结合。
- 支持 **本地化部署**，无需依赖外部 API，保护视频数据隐私。
- 输出为 **自包含 HTML 文件**，便于分享和离线查看，无需额外服务器。
- 基于 **DeepSeek V4 Flash Vision** 大模型，兼顾理解精度与推理速度。

# Skyvern 项目分析

## 1. 中文简介

Skyvern 是一款基于人工智能的浏览器自动化工具，能够智能地完成各类基于网页的工作流程。它利用大语言模型（LLM）和计算机视觉技术，让机器像人类一样操作浏览器，自动完成复杂的网页交互任务。

## 2. 核心功能

- **AI 驱动浏览器操作**：利用大语言模型理解网页内容并自动执行点击、填写、导航等操作
- **视觉感知能力**：结合计算机视觉技术识别页面元素，无需依赖固定选择器
- **可视化工作流编排**：支持通过界面配置和调度自动化任务流程
- **API 集成能力**：提供 API 接口，便于与企业现有系统无缝对接
- **支持主流浏览器自动化工具**：兼容 Playwright 等技术栈

## 3. 适用场景

- **RPA 替代方案**：替代传统规则型 RPA，处理非结构化网页操作
- **数据抓取与录入**：自动从网站提取数据或向网页表单批量填写信息
- **跨平台工作流自动化**：自动化跨多个网站/应用的重复性业务流程
- **替代 Power Automate**：为需要 AI 理解能力的场景提供更灵活的自动化选择

## 4. 技术亮点

- 将 **LLM + 计算机视觉** 结合用于浏览器自动化，突破了传统自动化工具依赖固定选择器的局限
- 支持 **自修复能力**：页面布局变化时仍能智能识别并操作目标元素

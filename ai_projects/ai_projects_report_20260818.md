# sprix-sage-router 项目分析

## 1. 中文简介
Sprix AI（屿智同行）推出的A2A代理网络智能路由系统，支持状态感知的SELF/COLLABORATE/HANDOFF三种路由模式。该系统能够根据任务状态动态调度多代理协作，实现高效的代理间任务分配与移交。

## 2. 核心功能
- **状态感知路由**：根据代理当前状态智能选择最优路由策略
- **三种路由模式**：支持SELF（自主处理）、COLLABORATE（协作处理）、HANDOFF（移交处理）
- **A2A代理编排**：为Agent-to-Agent网络提供任务调度与协调
- **动态任务分配**：根据任务复杂度和代理能力自动分配执行路径
- **多代理协同**：支持多个AI代理间的无缝协作与任务交接

## 3. 适用场景
- **复杂任务分解**：将大型任务拆分为子任务并分配给不同代理处理
- **多代理工作流**：需要多个专业代理协作完成的业务流程自动化
- **代理网络调度**：管理多个AI代理的资源分配和任务优先级
- **人机协作系统**：代理与人类操作者之间的任务移交与协同

## 4. 技术亮点
- 基于A2A协议标准，实现标准化的代理间通信
- 支持动态路由决策，可根据运行时状态调整策略
- 与Sprix AI生态深度集成，提供开箱即用的代理编排能力
- 轻量级Python实现，易于集成到现有AI应用架构中

# LlamaFactory 项目分析

## 1. 中文简介
LlamaFactory 是一个统一且高效的微调框架，支持 100 多种大语言模型（LLM）和视觉语言模型（VLM）的微调训练。该项目已获得 ACL 2024 学术认可，为开发者提供了一站式模型微调解决方案。

## 2. 核心功能
- 支持 100+ 主流大模型的高效微调，包括 LLaMA、Qwen、DeepSeek、Gemma 等
- 提供多种微调方法，包括 LoRA、QLoRA、全参数微调等
- 支持 RLHF（基于人类反馈的强化学习）对齐训练
- 兼容量化技术，降低显存占用，提升训练效率
- 集成指令微调（Instruction Tuning）和 Agent 开发能力

## 3. 适用场景
- 研究人员和开发者需要对多种大模型进行快速微调实验
- 资源有限的场景下，通过 QLoRA 和量化技术实现低成本微调
- 需要构建对齐人类偏好的 RLHF 训练流程
- 多模态视觉语言模型（VLM）的微调与部署

## 4. 技术亮点
- **统一框架**：一个项目支持百余种模型，无需切换不同工具
- **学术认可**：成果发表于 ACL 2024，具备学术权威性
- **高效优化**：结合 PEFT 技术和量化方案，显著降低显存需求
- **生态丰富**：标签涵盖 MoE、LLM、NLP 等热门方向，社区活跃度高

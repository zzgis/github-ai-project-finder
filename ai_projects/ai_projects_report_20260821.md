# LlamaFactory 项目分析

## 1. 中文简介
LlamaFactory 是一个统一且高效的大语言模型（LLM）与视觉语言模型（VLM）微调框架，支持 100+ 种模型。该项目已被 ACL 2024 收录，提供了一站式的模型训练与部署解决方案。

## 2. 核心功能
- 支持 100+ 种主流 LLM 和 VLM 的统一微调，包括 Llama、Qwen、DeepSeek、Gemma 等
- 提供 LoRA、QLoRA、全参数微调等多种高效微调策略
- 支持 RLHF（基于人类反馈的强化学习）对齐训练
- 内置量化技术（如 GPTQ、AWQ），降低显存占用
- 支持 Agent 构建和指令微调（Instruction Tuning）

## 3. 适用场景
- 研究人员和开发者快速微调开源大模型，无需从零搭建训练 pipeline
- 资源有限的用户通过 QLoRA + 量化技术，在消费级 GPU 上完成模型适配
- 企业级应用中对模型进行 RLHF 对齐，提升输出质量与安全性
- 多模态场景下对视觉语言模型（VLM）进行指令微调

## 4. 技术亮点
- **统一架构**：基于 Hugging Face Transformers 和 PEFT 库，兼容性强，一个框架覆盖百种模型
- **低资源友好**：QLoRA 技术可在单张消费级显卡上高效微调大模型
- **学术认可**：成果发表于 ACL 2024，具备学术严谨性
- **生态丰富**：涵盖从预训练、指令微调到 RLHF 对齐的完整链路

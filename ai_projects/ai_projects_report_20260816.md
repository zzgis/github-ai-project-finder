Ludwig 是一款低代码框架，用于构建自定义大语言模型（LLM）、神经网络及其他 AI 模型。它由 Uber 开源，支持通过声明式配置快速完成模型训练、评估与部署，大幅降低深度学习的使用门槛。

### 2. 核心功能
- **低代码/无代码建模**：通过 YAML 配置文件定义模型结构，无需编写大量代码即可训练模型。
- **支持多种模型类型**：涵盖深度学习、大语言模型微调、计算机视觉等多种架构。
- **内置实验管理与可视化**：提供训练过程监控、指标可视化及实验对比功能。
- **多模态支持**：同时支持文本、图像、表格等多种数据类型。
- **一键部署**：支持将训练好的模型快速导出并部署为 API 服务。

### 3. 适用场景
- **快速原型开发**：数据科学家希望在短时间内验证模型想法，无需深入代码细节。
- **LLM 微调**：针对特定任务对 Llama、Mistral 等开源大模型进行微调。
- **企业级 AI 应用落地**：团队需要标准化、可复用的模型训练与部署流程。
- **多模态数据分析**：同时处理表格数据、文本和图像的综合分析任务。

### 4. 技术亮点
- **声明式配置驱动**：通过简洁的 YAML 文件即可定义完整训练流程，降低使用门槛。
- **基于 PyTorch 构建**：底层依托成熟的 PyTorch 生态，兼顾灵活性与性能。
- **数据中心（Data-Centric）理念**：强调通过数据质量提升模型效果，而非仅依赖调参。
- **社区活跃、星标近 1.2 万**：拥有广泛的社区支持和持续迭代更新。

## LlamaFactory 项目分析

### 1. 中文简介
LlamaFactory 是一个统一高效的大语言模型（LLM）和视觉语言模型（VLM）微调框架，支持 100 多种模型的微调训练。该项目已被 ACL 2024 收录，旨在为研究者与开发者提供一站式、低门槛的模型微调解决方案。

### 2. 核心功能
- 支持 100+ 种主流 LLM 和 VLM 的统一微调，包括 Llama、Qwen、DeepSeek、Gemma 等。
- 提供多种高效微调方法，如 LoRA、QLoRA、全参数微调及 RLHF 训练。
- 集成量化技术，支持低精度部署与推理，降低显存占用。
- 内置指令微调（Instruction Tuning）流程，简化模型定制步骤。
- 兼容 Hugging Face Transformers 生态，便于快速上手与集成。

### 3. 适用场景
- 研究者或开发者需要对多种大模型进行快速微调与实验验证。
- 企业希望基于开源模型（如 Qwen、DeepSeek）定制行业专属模型。
- 资源有限的团队希望通过 QLoRA 等低资源方案实现模型适配。

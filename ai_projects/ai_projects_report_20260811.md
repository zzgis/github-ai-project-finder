# funNLP 项目分析

## 1. 中文简介

## 2. 核心功能
- **敏感词检测与语言识别**：支持中英文敏感词过滤、语言检测、手机号/身份证/邮箱抽取。
- **中文分词与词性标注**：集成jieba等分词工具，提供词性标注、句法分析、新词发现等功能。
- **命名实体识别与信息抽取**：支持NER、关系抽取、关键词抽取、事件抽取等任务。
- **情感分析与文本分类**：提供情感值计算、文本分类模型及多领域情感分析资源。
- **预训练语言模型**：收录BERT、GPT、ALBERT、ELECTREA等中文预训练模型。
- **知识图谱与问答系统**：包含知识图谱构建、问答系统、实体链接等工具。
- **语音识别与OCR**：提供ASR语音识别、中文OCR、语音情感分析等资源。

## 3. 适用场景
- **智能客服与聊天机器人开发**：利用对话语料、知识图谱和问答系统快速构建对话机器人。
- **舆情监控与内容审核**：通过敏感词检测和情感分析实现内容安全审核与舆情监控。
- **垂直领域知识图谱构建**：提供医疗、金融、法律等领域专用词库和NER工具。
- **NLP模型训练与实验**：集成大量数据集、预训练模型和竞赛方案，加速模型研发。

## 4. 技术亮点
- 收录了清华、百度等机构开源的中文预训练模型（如XLORE、中文BERT系列）。
- 整合了NLP竞赛TOP方案与代码，包含14万歌曲知识库问答、Siamese BiLSTM相似句判定等创新应用。

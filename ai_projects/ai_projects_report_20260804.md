# LlamaFactory 项目分析

## 1. 中文简介
LlamaFactory 是一个统一且高效的微调框架，支持 100 多种大语言模型（LLM）和视觉语言模型（VLM）的微调训练。该项目由 ACL 2024 会议收录，旨在为开发者提供一站式的大模型微调解决方案。

## 2. 核心功能
- 支持 100+ 主流大语言模型和视觉语言模型的统一微调
- 提供 LoRA、QLoRA 等高效参数微调（PEFT）方法
- 支持 RLHF（人类反馈强化学习）和指令微调训练
- 内置多种量化技术，降低显存占用和推理成本
- 兼容 Transformers 生态，开箱即用的训练流程

## 3. 适用场景
- 企业级大模型私有化部署与领域适配微调
- 研究人员快速验证不同模型的微调效果
- 资源受限环境下的低成本模型训练（QLoRA 量化方案）
- 多模态视觉语言模型的指令微调训练

## 4. 技术亮点
- **统一框架**：一套代码支持 100+ 模型，无需切换工具链
- **高效微调**：LoRA/QLoRA 方案大幅降低显存需求，单卡即可微调大模型
- **量化支持**：内置 4bit/8bit 量化，显著减少显存占用
- **多模态支持**：同时支持纯文本和视觉语言模型微调
- **社区活跃**：GitHub 星标 73750+，拥有活跃的开发者社区和持续更新

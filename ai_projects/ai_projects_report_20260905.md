## LlamaFactory 项目分析

### 1. 中文简介
LlamaFactory 是一个统一且高效的开源微调框架，支持对 100+ 种大语言模型（LLM）和视觉语言模型（VLM）进行微调，相关研究发表于 ACL 2024。

### 2. 核心功能
- 支持 100+ 种主流大模型（如 LLaMA、Qwen、DeepSeek、Gemma 等）的统一微调
- 提供多种高效微调方法，包括 LoRA、QLoRA、全参数微调等
- 内置 RLHF、DPO 等人类反馈对齐训练支持
- 支持量化训练（4bit/8bit），降低显存占用
- 提供 Web UI 界面，便于可视化配置和监控训练过程

### 3. 适用场景
- 研究者或开发者希望快速对多种大模型进行指令微调（Instruction Tuning）
- 资源有限的用户希望通过 QLoRA 等量化技术在消费级 GPU 上微调大模型
- 需要对齐训练有特定偏好或价值观的模型（如 RLHF/DPO 场景）
- 希望统一平台管理多个模型微调实验，降低工程成本

### 4. 技术亮点
- **统一架构**：一个框架兼容 100+ 模型，无需为不同模型编写独立代码
- **极致高效**：基于 Transformers 深度优化，显存占用低、训练速度快
- **零门槛上手**：提供 Web UI 和命令行两种交互方式，适合不同用户群体
- **社区活跃**：GitHub 星标数超过 7.4 万，生态成熟，持续维护更新

kornia是一个专为空间AI设计的几何计算机视觉库，基于PyTorch构建。它提供了一套可微分的图像处理算子，使研究人员和开发者能够在深度学习流水线中无缝集成传统计算机视觉技术。

## 2. 核心功能
- 提供100多个可微分的几何计算机视觉算子，支持梯度反向传播
- 内置丰富的图像处理功能，如滤波、变换、形态学操作等
- 与PyTorch生态深度集成，支持GPU加速和批量处理
- 提供相机标定、立体视觉、三维重建等高级几何算法
- 支持模块化设计，可灵活组合构建自定义视觉流水线

## 3. 适用场景
- **机器人视觉**：用于机器人导航、SLAM和三维感知任务
- **自动驾驶**：适用于环境理解、障碍物检测和车道线识别
- **医学影像分析**：支持可微分的图像配准和分割任务
- **AR/VR应用**：用于增强现实中的空间定位和图像合成

## 4. 技术亮点
- **可微分设计**：所有算子支持自动微分，可直接嵌入神经网络训练流程
- **JIT编译优化**：通过TorchScript实现高性能推理
- **硬件加速**：原生支持CUDA，充分利用GPU计算能力
- **开源社区活跃**：连续入选Hacktoberfest，拥有活跃的开发者社区

# LlamaFactory 项目分析

## 1. 中文简介

LlamaFactory 是一个统一且高效的大语言模型（LLM）与视觉语言模型（VLM）微调框架，支持 100+ 种模型。该研究发表于 ACL 2024，旨在为研究者和开发者提供一站式模型微调解决方案。

## 2. 核心功能

- **统一微调框架**：支持 100+ 种大语言模型和视觉语言模型的统一训练与微调
- **多种高效微调方法**：提供全参数微调、LoRA、QLoRA 等多种参数高效微调（PEFT）方案
- **对齐训练支持**：集成 RLHF（强化学习人类反馈）、DPO 等对齐训练算法
- **量化与推理优化**：支持模型量化部署及流式输出推理
- **可视化交互界面**：提供 Web UI，方便用户进行模型训练和监控

## 3. 适用场景

- 研究人员需要快速微调 LLaMA、Qwen、DeepSeek、Gemma 等主流大模型
- 开发者希望在有限计算资源下使用 QLoRA 等技术进行高效微调
- 团队需要进行指令微调（Instruction Tuning）或对齐训练（RLHF/DPO）
- 需要统一平台管理多个不同架构模型的微调任务

## 4. 技术亮点

- 支持 MoE（混合专家）架构模型的微调训练
- 兼容 Transformers 生态，无缝对接 Hugging Face 模型库
- 支持多模态模型（VLM）的联合微调
- 提供从数据处理到模型部署的完整流水线

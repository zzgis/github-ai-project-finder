Ludwig 是一款低代码框架，旨在帮助开发者快速构建自定义的大语言模型（LLM）、神经网络及其他 AI 模型。它通过声明式配置简化了机器学习模型的训练与部署流程，降低了 AI 开发的门槛。

## 2. 核心功能

- **低代码/声明式建模**：通过 YAML 配置文件定义模型结构，无需编写大量代码即可训练模型。
- **多模态支持**：支持文本、图像、表格、音频等多种数据类型，适用于 NLP、计算机视觉等任务。
- **预训练模型微调**：提供对 LLaMA、Mistral 等主流 LLM 的微调支持，便于快速适配下游任务。
- **自动化模型评估**：内置可视化评估指标和结果展示，方便监控模型训练过程。
- **端到端训练部署**：从数据处理到模型训练、评估和部署，提供完整的流水线支持。

## 3. 适用场景

- **快速原型开发**：数据科学家希望在短时间内验证想法，无需深入框架细节。
- **LLM 微调**：对 LLaMA、Mistral 等大语言模型进行领域适配和任务微调。
- **多模态应用构建**：需要同时处理文本、图像等异构数据的 AI 应用开发。
- **企业级模型部署**：需要标准化、可复现的机器学习流水线，降低维护成本。

## 4. 技术亮点

- **基于 PyTorch 构建**：充分利用 PyTorch 生态，兼容主流深度学习库。
- **数据中心（Data-Centric）理念**：强调数据质量对模型性能的影响，提供数据预处理和增强工具。
- **可扩展架构**：支持自定义组件和扩展，可灵活适配不同业务需求。
- **社区活跃**：GitHub 星标数超过 11,000，拥有活跃的开源社区和持续更新。

Kornia 是一个面向空间人工智能的几何计算机视觉库，基于 PyTorch 构建。它为深度学习研究者提供了一套可微分的计算机视觉原语，使传统视觉算法能够无缝集成到神经网络中。

## 2. 核心功能
- 提供可微分的几何计算机视觉算子，支持端到端训练
- 基于 PyTorch 实现，与现有深度学习生态无缝兼容
- 涵盖图像变换、相机标定、立体视觉等核心视觉任务
- 支持批量处理，优化 GPU 并行计算性能
- 提供丰富的图像处理与增强工具集

## 3. 适用场景
- 机器人视觉与空间感知系统开发
- 自动驾驶中的几何视觉任务
- 神经渲染与三维重建研究
- 可微分计算机视觉算法实验

## 4. 技术亮点
- **可微分设计**：将传统几何视觉算法转化为可微分操作，支持梯度反向传播
- **PyTorch 原生集成**：完全基于 PyTorch 实现，无需额外依赖

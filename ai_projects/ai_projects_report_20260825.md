## 项目分析：deepseek-v4-flash-vision-video-rag

---

### 1. 中文简介

该项目是一个基于 DeepSeek 视觉大模型的视频理解与问答 Agent 技能，能让 AI 真正"看懂"视频内容。用户可对视频提问，系统会返回答案、精确时间戳（第几分几秒），并自动截取对应的可播放片段和关键帧供用户核对。

---

### 2. 核心功能

- **视频智能理解**：基于 DeepSeek V4-Flash-Vision 视觉大模型，实现对视频内容的深度分析。
- **时间轴抽帧索引**：按时间轴对视频进行抽帧并建立一次性索引，便于快速检索。
- **三阶段问答流程**：本地粗筛 → 视觉精排 → 深度阅读回答，层层递进提升准确性。
- **时间戳引用**：答案附带 `[MM:SS]` 格式的时间戳，精准定位信息来源。
- **自动生成 HTML 预览页**：输出自包含的 HTML 文件，内嵌可播放片段、关键帧和答案，双击即可在浏览器中查看。

---

### 3. 适用场景

- **视频内容检索**：从长视频中快速定位特定事件或信息片段。
- **教学/培训视频问答**：对课程视频提问，获取带时间戳的答案和对应画面。
- **监控/录像分析**：快速查找特定时间段的关键画面并生成分析报告。
- **视频素材管理**：为视频库建立可检索的内容索引，提升素材利用效率。

---

### 4. 技术亮点

- **RAG 架构应用于视频**：将检索增强生成（RAG）技术延伸至视频理解领域，实现"先检索、后回答"的精准推理。
- **本地 + 视觉双阶段处理**：先用本地索引粗筛候选片段，再用视觉模型精排，兼顾效率与准确性。
- **零依赖 HTML 输出**：生成的预览页为自包含文件，无需服务器即可离线查看。
- **Agent Skill 形式封装**：以 skill 形式集成，便于在其他 Agent 框架中复用和扩展。

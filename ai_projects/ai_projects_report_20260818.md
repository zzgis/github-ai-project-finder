ONNX（Open Neural Network Exchange）是一个开源标准，旨在实现机器学习模型在不同框架之间的互操作性。它允许开发者轻松地将模型从一种框架（如PyTorch、TensorFlow）转换为另一种框架，打破平台壁垒。

## 2. 核心功能
- **跨框架模型转换**：支持在PyTorch、TensorFlow、Keras等主流框架之间转换模型
- **统一模型表示**：提供标准化的模型格式，确保不同平台间的兼容性
- **推理优化**：支持模型优化和加速，提升推理性能
- **生态兼容性**：与多种硬件平台和推理引擎（如ONNX Runtime）无缝集成

## 3. 适用场景
- **模型迁移**：将训练好的模型从研究框架部署到生产环境
- **跨平台部署**：在不同硬件（CPU、GPU、移动端）上运行同一模型
- **框架选型灵活**：允许团队根据需求选择最适合的训练框架，同时保持部署灵活性
- **模型优化**：利用ONNX优化工具对模型进行剪枝、量化等操作

# LlamaFactory 项目分析

## 1. 中文简介
LlamaFactory 是一个统一高效的大语言模型（LLM）与视觉语言模型（VLM）微调框架，支持 100 多种主流模型。该项目在 ACL 2024 上发表，旨在为研究者与开发者提供简洁易用的微调解决方案。

## 2. 核心功能
- 支持 100+ 种主流 LLM 和 VLM 的统一微调，涵盖 LLaMA、Qwen、DeepSeek、Gemma 等模型。
- 提供多种高效微调方法，包括 LoRA、QLoRA、全参数微调及 P-Tuning 等。
- 支持 RLHF（基于人类反馈的强化学习）和 DPO 等对齐训练策略。
- 内置量化支持（如 4-bit/8-bit 量化），降低显存占用，适合消费级显卡。
- 提供开箱即用的训练脚本与 Web UI，简化微调流程。

## 3. 适用场景
- **研究者/开发者**：快速对多种大模型进行指令微调或对齐训练，无需重复搭建训练环境。
- **企业/团队**：基于开源模型微调定制专属垂直领域模型（如客服、医疗、法律）。
- **个人爱好者**：在有限显存条件下（如单张 24GB 显卡）高效微调 LLM。
- **多模态应用**：对视觉语言模型（VLM）进行微调，实现图文理解与生成任务。

## 4. 技术亮点
- **统一架构**：一套代码支持 100+ 模型，大幅降低多模型适配成本。
- **ACL 2024 学术背书**：经同行评审，方法论严谨，具备学术可信度。
- **量化 + LoRA 组合优化**：QLoRA 技术实现低显存高效微调，突破硬件限制。
- **完整训练链路**：从数据预处理、指令微调到 RLHF/DPO 对齐，全流程覆盖。

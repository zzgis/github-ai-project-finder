# GitHub 项目分析：deepseek-v4-flash-vision-video-rag

---

## 1. 中文简介
该项目是一个基于 DeepSeek 视觉大模型的视频理解与问答 Agent 技能，能让 AI 真正"看懂"视频内容。用户可对视频提问，系统会返回答案、对应时间戳，并生成包含可播放片段和关键帧的自包含 HTML 预览页供核对。

---

## 2. 核心功能
- **视频智能理解**：基于 DeepSeek V4-Flash Vision 视觉大模型对视频内容进行深度解析。
- **时间轴抽帧索引**：按时间轴抽取关键帧并建立索引（一次性处理），加速后续检索。
- **多级检索流程**：采用"本地粗筛 → 视觉精排 → 深度阅读回答"的三级处理策略。
- **带时间戳的答案引用**：回答附带 [MM:SS] 格式的时间戳，精准定位答案位置。
- **自包含 HTML 预览**：自动生成内嵌视频片段、关键帧和答案的 HTML 页面，双击浏览器即可查看。

---

## 3. 适用场景
- **视频内容检索**：从长视频中快速定位特定信息片段。
- **在线教育/培训**：对教学视频进行智能问答，辅助学习复习。
- **会议/讲座视频分析**：从会议录像中提取关键内容并生成摘要。
- **监控视频排查**：快速查找监控视频中的特定事件或目标。

---

## 4. 技术亮点
- **RAG 架构应用于视频理解**：将检索增强生成（RAG）技术成功迁移到视频领域，实现高效的视频内容问答。
- **本地+云端协同处理**：本地粗筛降低 API 调用成本，视觉精排保证回答质量，兼顾效率与准确性。
- **开箱即用的 HTML 输出**：生成的自包含 HTML 文件无需额外依赖，便于分享和存档。

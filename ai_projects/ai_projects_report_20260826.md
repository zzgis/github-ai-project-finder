# LlamaFactory 项目分析

## 1. 中文简介
LlamaFactory 是一个统一且高效的大语言模型（LLM）与视觉语言模型（VLM）微调框架，支持 100+ 种主流模型。该项目在 ACL 2024 发表，旨在为用户提供简洁易用的模型微调解决方案。

## 2. 核心功能
- 支持 100+ 种主流 LLM 和 VLM 的统一微调，涵盖 Llama、Qwen、DeepSeek、Gemma 等模型
- 提供 LoRA、QLoRA、全参数微调等多种参数高效微调（PEFT）方法
- 支持多种量化方案（4-bit/8-bit），降低显存占用并提升训练效率
- 内置 RLHF（基于人类反馈的强化学习）训练能力，支持指令微调与对齐优化
- 提供简洁的命令行和 Web UI 界面，降低大模型微调的技术门槛

## 3. 适用场景
- 研究人员和开发者对开源大模型进行领域适配和指令微调
- 需要在有限显存条件下高效微调大规模语言模型
- 希望快速上手大模型微调、降低工程复杂度的团队或个人
- 需要多模态（图文）模型微调及 RLHF 对齐训练的场景

## 4. 技术亮点
- **统一框架**：将 100+ 模型整合到同一套训练流程中，无需为每种模型单独配置
- **极致效率**：QLoRA 等量化微调技术可在消费级显卡上运行大规模模型
- **多模态支持**：不仅支持纯文本 LLM，还兼容视觉语言模型（VLM）的微调
- **完整生态**：从数据处理、训练到评估形成闭环，并集成 Transformers 等主流生态

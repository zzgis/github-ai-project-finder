### shuohao-skills
- **中文简介**
shuohao-skills 是一套专为 AI 编码 Agent（如 Claude Code 和 Codex）设计的技能集合。其中 novel-characters 模块可将小说内容自动转化为角色设定集，涵盖人物画像、卡通形象提示词、音色描述及三视图生成提示。

**核心功能**
1. 提供兼容 Claude Code 和 Codex 的 AI 编码 Agent 技能工具集。
2. 支持将小说文本自动拆解并生成结构化的人物角色设定集。
3. 能够生成卡通形象设计提示词（Prompts）及音色特征描述。
4. 可输出用于角色设计的三视图（正侧背）生成提示。
5. 基于 JavaScript 开发，便于集成到现有 AI 工作流中。

**适用场景**
1. 使用 Claude Code 或 Codex 进行自动化编程开发时调用额外技能。
2. 网文作者或小说编辑用于快速建立角色档案和视觉设定。
3. AI 绘画创作者需要批量生成特定角色风格的提示词时。
4. 游戏或动画制作前期，需要快速将文字角色转化为可视化设计参考。

**技术亮点**
- 跨平台兼容：同时支持 Claude Code 和 OpenAI Codex 两种主流 AI 编码 Agent。
- 垂直领域优化：针对“小说转角色设定”这一特定场景提供了端到端的提示词生成能力。
- 链接: https://github.com/eternityspring/shuohao-skills

### kornia
- ### 项目分析：Kornia

#### 1. 中文简介
Kornia 是一个专为空间 AI 设计的几何计算机视觉库，基于 PyTorch 构建。它将传统的计算机视觉算法与深度学习无缝集成，支持在 GPU 上高效执行可微分的图像处理操作。该库旨在简化从经典视觉到神经网络的开发流程，适用于机器人、自动驾驶等领域。

#### 2. 核心功能
- **可微分图像处理**：提供基于 GPU 加速的几何变换、色彩空间转换和形态学操作，所有操作均可微分，便于集成到神经网络中。
- **几何视觉算法**：内置相机标定、单应性估计、对极几何等经典几何视觉模块，支持端到端的视觉任务训练。
- **PyTorch 原生集成**：完全兼容 PyTorch 生态，支持自动微分（autograd），可直接用于损失函数计算和模型优化。
- **多分辨率与批量处理**：高效支持批量图像处理和多尺度分析，适用于大规模数据集训练和实时视频流处理。
- **模块化设计**：提供清晰的分层 API，涵盖基础图像操作、几何模型和高级视觉任务，便于扩展和定制。

#### 3. 适用场景
- **机器人视觉导航**：用于构建可微分的 SLAM 系统或视觉伺服控制，实现实时环境感知与定位。
- **自动驾驶感知**：开发端到端的深度估计、运动恢复结构（SfM）或相机标定模块，提升系统精度。
- **医学图像分析**：处理可微分的图像配准、分割预处理流程，加速医学影像模型的训练与优化。
- **增强现实（AR）**：实现实时姿态估计、平面检测和图像变形，支持 AR 应用中的空间对齐需求。

#### 4. 技术亮点
- **端到端可训练性**：打破传统计算机视觉与深度学习的壁垒，允许将几何约束直接嵌入神经网络训练过程。
- **硬件加速优化**：所有算法均针对 GPU 进行优化，显著提升大规模图像处理效率。
- **开源社区活跃**：作为 Hacktoberfest 参与项目，拥有活跃的开发者社区和丰富的文档支持。

LlamaFactory 是一个统一且高效的大语言模型（LLM）和视觉语言模型（VLM）微调框架，支持 100 多种模型的微调训练。该项目已发表于 ACL 2024，为研究者和开发者提供了一个开箱即用的模型微调解决方案。

## 2. 核心功能
- 支持 100+ 种大语言模型和视觉语言模型的统一微调
- 提供 LoRA、QLoRA、P-Tuning 等多种高效微调方法
- 集成 RLHF（基于人类反馈的强化学习）和 DPO 等对齐技术
- 支持量化训练（4/8/16 位），降低显存需求
- 兼容 Transformers 生态，易于集成和扩展

## 3. 适用场景
- 企业级大模型定制：基于开源模型（如 Llama、Qwen、DeepSeek）进行领域微调
- 多模态应用开发：对视觉语言模型进行指令微调，支持图文理解任务
- 资源受限环境：利用 QLoRA 和量化技术，在消费级 GPU 上完成模型微调
- 强化学习对齐：对模型进行 RLHF/DPO 训练，提升输出质量和安全性

## 4. 技术亮点
- **统一架构**：一套代码支持百种模型，降低多模型适配成本
- **高效微调**：原生支持 LoRA/QLoRA，显存占用仅为全参数微调的 1/4
- **多模态支持**：不仅限于文本模型，还覆盖视觉语言模型（VLM）
- **生产友好**：提供 Web UI 和命令行双模式，兼顾易用性与灵活性
- **学术认可**：成果发表于 ACL 2024，具备学术背书

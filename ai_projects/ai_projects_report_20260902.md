Skyvern 是一款基于 AI 的浏览器自动化框架，能够智能地完成各类网页操作工作流。它利用大语言模型和计算机视觉技术，让自动化任务更加灵活和智能化，无需编写复杂的自动化脚本。

## 2. 核心功能
- **AI 驱动的浏览器自动化**：通过 LLM 理解页面内容并自动执行操作
- **支持多种浏览器引擎**：兼容 Playwright、Puppeteer 和 Selenium
- **计算机视觉辅助**：结合视觉识别技术完成复杂页面交互
- **API 友好设计**：提供简洁的 API 接口，便于集成到现有系统
- **工作流自动化**：支持定义和执行复杂的跨页面工作流

## 3. 适用场景
- **RPA 自动化**：替代传统 RPA 工具（如 Power Automate），自动化重复性网页操作
- **数据采集与爬虫**：智能抓取需要登录或复杂交互的动态网页数据
- **测试自动化**：用自然语言描述测试场景，自动生成并执行浏览器测试
- **业务流程自动化**：自动化处理跨多个网页系统的业务操作

## 4. 技术亮点
- 将大语言模型能力与浏览器自动化相结合，降低了自动化脚本的开发门槛
- 采用多引擎架构，可根据需求灵活选择 Playwright、Puppeteer 或 Selenium
- 视觉识别与语义理解双重能力，可处理传统自动化难以覆盖的动态页面场景

### 2. 核心功能

- **PyTorch 原生集成**：与 PyTorch 张量无缝协作，可直接嵌入深度学习模型

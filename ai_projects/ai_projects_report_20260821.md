# funNLP 项目分析

## 1. 中文简介

funNLP 是一个面向中文自然语言处理（NLP）的综合性资源仓库，汇集了敏感词检测、分词、词向量、知识图谱、预训练模型、数据集、工具库等各类NLP相关资源。该项目由社区维护，整合了大量开源工具和前沿研究成果，是中文NLP开发者的实用工具集合。

## 2. 核心功能

- **文本处理工具**：敏感词检测、繁简转换、中英文分词、停用词过滤、文本纠错与可读性评估
- **信息抽取与识别**：手机号/邮箱/身份证抽取、命名实体识别（NER）、关系抽取、事件抽取
- **词库与知识资源**：中日文人名库、中文缩写库、成语/诗词/古诗词库、汽车品牌词库、医学/法律/财经领域词库
- **预训练模型与向量**：中文BERT/ALBERT/ELECTREA等预训练模型、word2vec词向量、多语言句向量
- **对话与生成系统**：聊天机器人（seqGAN/GPT2）、自动对联、歌词生成器、文本摘要与关键词提取

## 3. 适用场景

- **内容审核平台**：利用敏感词库、暴恐词表、反动词表进行文本安全检测
- **智能客服/聊天机器人**：基于预训练模型和对话数据集快速构建领域对话系统
- **知识图谱构建**：使用实体识别、关系抽取工具和百科数据构建中文知识图谱
- **NLP研究与教学**：获取高质量数据集、基准测评任务和开源代码实现

## 4. 技术亮点

- 项目整合了清华XLORE跨语言知识图谱、百度ERNIE、OpenCLaP、UER等国内主流预训练模型
- 涵盖从传统NLP（jieba分词、HMM）到深度学习（BERT、GPT2、ALBERT）的完整技术栈
- 提供了多个竞赛TOP方案复盘和基准测评（CLUE、CLUENER），便于研究者对标前沿成果
- 包含大量垂直领域资源（医疗、金融、法律、汽车等），适合行业定制化开发
- 链接: https://github.com/fighting41love/funNLP

# ONNX 项目分析

## 1. 中文简介
ONNX（开放神经网络交换）是一个开源的机器学习互操作标准，旨在实现不同深度学习框架之间的模型兼容与转换。它允许开发者在不同平台之间无缝迁移模型，打破框架壁垒，提升模型部署的灵活性。

## 2. 核心功能
- 提供统一的模型格式，支持跨框架的模型转换与互操作
- 兼容主流深度学习框架，如 PyTorch、TensorFlow、Keras 和 scikit-learn
- 支持模型在训练框架与推理引擎之间的高效迁移
- 提供丰富的算子库，覆盖常见的神经网络层与操作
- 支持多平台部署，包括移动端、嵌入式设备和云环境

## 3. 适用场景
- 将 PyTorch 或 TensorFlow 训练的模型转换为统一格式，便于跨平台部署
- 在移动端或嵌入式设备上运行深度学习模型
- 在不同深度学习框架之间迁移模型，避免重新训练
- 在推理优化引擎（如 ONNX Runtime）中加速模型推理

## 4. 技术亮点
- 由微软、Facebook 等科技巨头联合推动，生态成熟且社区活跃
- 支持动态形状和复杂模型结构，兼容性强

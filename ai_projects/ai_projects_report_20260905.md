## n8n 项目分析

### 1. 中文简介
n8n 是一个公平代码的工作流自动化平台，内置原生 AI 能力。支持可视化构建与自定义代码相结合，可自托管或云端部署，提供 400+ 种集成。

### 2. 核心功能
- **可视化工作流构建**：通过拖拽节点方式创建自动化流程，支持低代码/无代码开发
- **原生 AI 集成**：内置 AI 能力，支持 MCP（Model Context Protocol）客户端与服务端
- **400+ 集成连接**：覆盖主流 API 和 SaaS 服务，实现跨平台数据互通
- **灵活部署模式**：支持自托管（Self-hosted）和云端托管两种方式
- **自定义代码扩展**：允许嵌入 JavaScript/TypeScript 代码进行深度定制

### 3. 适用场景
- **企业自动化**：自动化日常业务流程，如审批流、数据同步、通知推送
- **数据集成与 ETL**：跨系统数据抽取、转换和加载，实现数据管道自动化
- **AI 工作流编排**：结合 LLM 能力构建智能助手、内容生成、数据分析等 AI 应用
- **API 编排与集成**：将多个 API 串联，构建复杂的服务调用链

### 4. 技术亮点
- 采用 **TypeScript** 开发，类型安全且生态友好
- 支持 **MCP 协议**（MCP Client/Server），可与主流 AI 模型深度集成
- **Fair-code 许可证**，在开源与商业使用之间取得平衡

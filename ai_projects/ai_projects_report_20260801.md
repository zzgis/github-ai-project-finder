# bindwidth 项目分析

## 1. 中文简介
bindwidth 是一款面向本地部署（on-prem）大语言模型推理的容量规划与总拥有成本（TCO）计算工具，能够基于实际证据数据帮助用户评估硬件配置需求。

## 2. 核心功能
- 基于实际推理数据评估 LLM 本地部署的硬件容量需求
- 计算本地部署大模型的总体拥有成本（TCO）
- 提供证据驱动的推理 sizing 建议，减少估算误差
- 支持 JavaScript 环境快速部署和使用

## 3. 适用场景
- 企业评估自建 LLM 推理基础设施的硬件选型
- 对比本地部署与云端推理的成本差异
- IT 团队进行 AI 基础设施预算规划
- 技术决策者验证推理规模的可行性

## 4. 技术亮点
该项目以"证据感知"为核心特点，强调基于实际数据而非理论峰值进行容量规划，有助于避免因过度配置导致的资源浪费，同时帮助决策者更精准地估算本地部署 LLM 的真实成本。

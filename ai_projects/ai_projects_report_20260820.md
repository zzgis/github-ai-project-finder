## LlamaFactory 项目分析

### 1. 中文简介
LlamaFactory 是一个统一且高效的微调框架，支持对 100 多种大语言模型（LLM）和视觉语言模型（VLM）进行训练，相关研究成果发表于 ACL 2024 会议。该项目提供了从零开始预训练、指令微调、偏好对齐等完整的训练流程。

### 2. 核心功能
- 支持 100+ 主流大模型，涵盖 Llama、Qwen、DeepSeek、Gemma、GPT-2 等多种架构
- 提供完整的训练流程，包括预训练、指令微调、RLHF 偏好对齐等
- 支持 LoRA、QLoRA、DoRA 等参数高效微调（PEFT）方法，显著降低显存需求
- 支持多模型合并、量化部署（4/8/16-bit）及 Agent 工具调用能力
- 提供 Web UI 界面，便于可视化训练过程与模型管理

### 3. 适用场景
- 个人开发者或团队对开源大模型进行领域定制化微调
- 需要低成本微调大模型的研究人员（QLoRA 量化方案支持消费级显卡）
- 企业用户构建专属 AI 助手、智能客服等应用
- 多模态（图文）大模型的训练与优化

### 4. 技术亮点
- **统一框架**：一套代码支持 100+ 模型，无需针对不同模型编写独立训练脚本
- **ACL 2024 学术背书**：方法经过同行评审，具备学术严谨性
- **极致易用性**：提供 Web UI 和命令行双模式，新手友好
- **训练效率优化**：支持 FlashAttention、Galore、NEFTune 等前沿训练加速与优化技术

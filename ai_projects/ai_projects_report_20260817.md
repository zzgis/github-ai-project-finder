# GitHub 项目分析：ai-data-extractor

## 1. 中文简介
这是一个免费开源的 AI 编程助手聊天记录提取工具，支持从 Claude Code、Cursor、Windsurf、Aider、Cline/Roo Code 等多种主流 AI 编程助手中导出对话数据。开发者可以使用 Python 脚本将这些聊天记录批量转换为结构化格式，便于后续分析或迁移。

## 2. 核心功能
- 支持从多种 AI 编程助手平台提取聊天记录数据
- 提供批量导出功能，可一键处理多个对话记录
- 将非结构化对话内容转换为结构化格式（如 JSON）
- 兼容 Claude Code、Cursor、Windsurf、Aider、Cline/Roo Code 等主流工具
- 完全开源免费，基于 Python 实现，易于部署和使用

## 3. 适用场景
- **数据迁移**：将不同 AI 编程助手的聊天记录迁移到新平台
- **对话备份**：定期备份重要的 AI 编程对话，防止数据丢失
- **历史分析**：分析过去的编程对话，提取有价值的代码片段或解决方案
- **知识沉淀**：将 AI 辅助编程的经验整理成文档或知识库

## 4. 技术亮点
- 采用 Python 编写，代码简洁，依赖轻量，易于二次开发
- 支持多平台适配，统一接口提取不同助手的对话数据
- 开源项目，社区可贡献扩展更多 AI 编程助手的支持
- 链接: https://github.com/bawadou/ai-data-extractor

- 通过递归查询实现实体关系的记忆检索
- 提供提示词钩子（prompt hook）将记忆注入AI对话
- 轻量级实现，无复杂依赖
- 支持AI助手的上下文记忆能力

### 3. 适用场景

- 个人助手应用中的长期记忆管理
- 需要低成本知识图谱记忆的轻量级项目

### 4. 技术亮点
- 极简设计：仅用三个表+一条递归查询实现完整记忆功能
- 零外部依赖：纯SQLite实现，部署简单
- 提示词钩子机制便于与各类LLM框架集成

# 项目分析：bindwidth

## 1. 中文简介

bindwidth 是一款面向本地部署大语言模型（LLM）推理场景的容量规划与总拥有成本（TCO）计算器。它基于实际证据数据，帮助用户评估硬件配置需求并测算部署成本，为私有化部署决策提供量化依据。

## 2. 核心功能

- **推理容量规划**：根据模型规模和并发需求，计算所需的 GPU/硬件配置
- **TCO 成本测算**：综合硬件采购、运维、能耗等成本，计算私有化部署的总拥有成本
- **证据驱动评估**：基于真实基准测试数据，提供可靠的性能预估而非理论值
- **本地部署优化**：专注于企业私有化部署场景的硬件选型建议
- **多模型支持**：兼容主流开源 LLM 模型的推理需求分析

## 3. 适用场景

- 企业评估从云 API 迁移至本地部署 LLM 的成本效益
- IT 团队进行 GPU 服务器采购前的硬件配置规划
- 技术决策者对比不同 LLM 部署方案的总拥有成本
- 需要精确预算规划的 AI 基础设施建设项目

## 4. 技术亮点

- 采用 JavaScript 开发，跨平台兼容，部署便捷
- 聚焦"证据驱动"理念，避免纯理论估算的偏差
- 针对本地部署这一细分场景提供专业化测算工具

# 项目分析：graph-memory-starter

## 1. 中文简介
这是一个为AI助手提供知识图谱记忆功能的项目。它通过三个SQLite表、一个递归查询和一个prompt钩子来实现记忆的存储与检索。

## 2. 核心功能
- 基于SQLite的知识图谱记忆持久化存储
- 递归查询支持多层级关系推理与记忆检索
- Prompt钩子将记忆内容动态注入AI对话上下文
- 极简三表架构实现实体、关系与属性的完整建模
- 纯Python实现，零外部依赖，轻量易部署

## 3. 适用场景
- AI聊天机器人需要跨会话的长期记忆能力
- 智能助手需关联用户历史对话与知识背景
- 需要上下文关联的多轮对话系统
- 轻量级知识管理应用，无需复杂数据库服务

## 4. 技术亮点
- **极简架构**：仅用三个表即可实现完整的知识图谱记忆，降低维护成本
- **递归查询**：通过单一递归查询支持任意深度的关系链推理
- **低门槛集成**：Prompt钩子设计让记忆功能可无缝嵌入现有AI助手框架
- **零依赖部署**：纯Python + SQLite，无需额外数据库服务，开箱即用

## doc7 项目分析

### 1. 中文简介
doc7 是一款开源文档 AI 工具，能够将 PDF 和 Word 文档转换为 AI 可直接使用的 Markdown 格式。它通过多模态视觉语言模型理解文档内容，在转换过程中保留文档的视觉结构与排版信息。

### 2. 核心功能
- 支持将 PDF 和 DOCX 文档转换为 Markdown 格式
- 利用视觉语言模型（VLM）理解文档的视觉布局和内容
- 支持多模态处理，可识别文档中的图片、表格和文本结构
- 支持本地 AI 部署，保障数据隐私安全
- 开源免费，可自由定制和扩展

### 3. 适用场景
- **知识库构建**：将大量 PDF/Word 文档批量转换为 Markdown，用于构建 RAG 知识库
- **AI 训练数据准备**：将非结构化文档转换为 AI 可解析的结构化 Markdown 格式
- **本地化文档处理**：对数据隐私要求较高的场景，可在本地运行完成文档转换
- **多模态内容提取**：需要同时处理文档中的文本、图片和表格的场景

### 4. 技术亮点
- 基于视觉语言模型实现文档理解，而非简单的文本提取，能够还原文档的视觉结构
- 纯 Go 语言开发，跨平台兼容性好，运行效率高
- 支持本地部署，避免敏感数据上传至云端，适合企业级应用场景
- 链接: https://github.com/magicrew/doc7
- ⭐ 112 | 🍴 3 | 语言: Go

这是一个基于PyTorch的计算机视觉可解释性工具库，支持多种模型结构和任务类型。通过Grad-CAM及其变体算法，帮助用户可视化深度学习模型的决策依据，提升模型透明度。

## 2. 核心功能
- 支持CNN和Vision Transformer等多种网络架构的可视化
- 提供Grad-CAM、Score-CAM等多种经典解释性算法实现
- 覆盖图像分类、目标检测、图像分割等主流视觉任务
- 支持图像相似度分析等扩展应用场景

## 3. 适用场景
- 深度学习模型调试与结果验证
- AI可解释性研究与教学演示
- 计算机视觉任务中的决策过程分析
- 模型性能评估与问题定位

## 4. 技术亮点
- 统一接口设计，兼容多种主流深度学习框架
- 支持自定义模型结构，扩展性强
- 丰富的可视化输出，便于结果展示与分析
- 社区活跃，星标数超过1.2万，文档完善

## n8n 项目分析

### 1. 中文简介
n8n 是一个采用公平代码许可证的工作流自动化平台，内置原生 AI 能力。它结合了可视化拖拽构建与自定义代码开发，支持自托管或云端部署，并提供 400 多种集成连接。

### 2. 核心功能
- **可视化工作流构建**：通过拖拽节点快速设计自动化流程，无需编写代码即可上手
- **原生 AI 集成**：内置 AI 能力，可直接在工作流中调用 AI 模型和智能处理
- **400+ 应用集成**：提供丰富的预置连接器，覆盖主流 SaaS 服务和 API
- **灵活部署模式**：支持自托管（私有化部署）和云端托管两种方式
- **MCP 协议支持**：原生支持 Model Context Protocol，可与 AI 工具链深度集成

### 3. 适用场景
- **企业自动化流程**：自动处理审批、通知、数据同步等重复性业务操作
- **AI 工作流编排**：将 AI 模型能力整合到自动化管道中，实现智能数据处理
- **API 集成与数据同步**：连接不同系统间的数据流，实现跨平台信息同步
- **低代码/无代码开发**：非技术人员也能快速搭建复杂的应用集成方案

### 4. 技术亮点
- 采用 **fair-code 许可证**，在开源与商业使用之间取得平衡
- 基于 **TypeScript** 开发，类型安全且易于扩展
- 支持 **MCP（Model Context Protocol）**，为 AI 代理提供标准化的上下文交互能力
- 灵活的节点系统，允许通过 **自定义代码** 扩展功能边界

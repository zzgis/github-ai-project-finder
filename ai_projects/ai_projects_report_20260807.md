### shuohao-skills
- ### 1. 中文简介
该项目为 AI 编码 Agent（如 Claude Code 和 Codex）提供了一套技能集合。其中包含名为 `novel-characters` 的技能，可将小说内容自动转化为完整的人物设定集，涵盖人物画像、卡通形象提示词、音色提示词及三视图设计。

### 2. 核心功能
- **多平台兼容**：同时支持 Claude Code 和 Codex 等主流 AI 编码 Agent 运行。
- **小说角色提取**：自动从小说文本中拆解并生成结构化的人物设定。
- **多模态提示词生成**：输出卡通形象设计提示词及角色音色描述，辅助视觉与音频创作。
- **三视图输出**：生成角色标准的三视图（正面、侧面、背面）设计参考。
- **JavaScript 实现**：基于 JavaScript 开发，便于集成和二次开发。

### 3. 适用场景
- **网文/IP 改编**：将小说快速转化为影视或游戏开发所需的人物设定文档。
- **AI 绘画辅助**：为 Midjourney、Stable Diffusion 等工具提供标准化的角色视觉提示词。
- **有声书制作**：根据角色设定生成音色提示词，辅助 AI 配音工具进行角色声音定制。
- **创意写作支持**：帮助作者系统化梳理人物形象，保持角色设定的一致性。

### 4. 技术亮点
- **跨 Agent 通用性**：一次开发即可在 Claude Code 和 Codex 两大生态中复用，降低适配成本。
- **垂直领域深度优化**：针对“文本转角色资产”这一垂直场景提供端到端解决方案，而非通用编码工具。
- **多模态输出能力**：同时处理文本（设定）、图像（提示词）和音频（音色）三种模态，扩展性强。
- 链接: https://github.com/eternityspring/shuohao-skills

### kornia
- **中文简介**
Kornia 是一个专为 Spatial AI 设计的几何计算机视觉库，基于 PyTorch 构建。它提供了可微分的传统计算机视觉算法，能够无缝集成到深度学习工作流中。该库旨在简化视觉模型的开发与部署过程。

**核心功能**
1. 提供完整的可微分几何视觉算子，支持端到端梯度计算。
2. 深度集成 PyTorch，兼容现有深度学习生态。
3. 包含丰富的图像处理、相机标定和三维几何工具。
4. 支持自动求导，便于在神经网络中直接使用传统 CV 算法。

**适用场景**
1. 构建需要几何约束的深度神经网络（如单目深度估计、SLAM）。
2. 机器人视觉系统中的实时空间感知与定位。
3. 将传统计算机视觉算法嵌入可微分管道进行联合优化。

**技术亮点**
- 核心优势在于其“可微分性”，允许传统 CV 模块作为神经网络层直接参与训练，突破了传统 CV 与深度学习之间的壁垒。

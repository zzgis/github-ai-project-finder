# x64dbg-mcp-server 项目分析

## 1. 中文简介
x64dbg-MCP Server 是一个面向 x64dbg 的原生 MCP（Model Context Protocol）插件，通过 HTTP 暴露调试器的完整功能。连接任意兼容 MCP 的 AI 助手即可程序化控制 x64dbg，实现设置断点、单步执行、读取内存、转储寄存器等功能。项目使用 Zig 语言开发，零依赖、单二进制输出、跨平台。

## 2. 核心功能
- 通过 HTTP 协议暴露 x64dbg 全部调试功能
- 支持设置断点、单步执行、读取内存、转储寄存器
- 兼容 MCP 协议的 AI 助手可编程调用
- 单二进制文件部署，无需额外依赖

## 3. 适用场景
- **自动化逆向分析**：AI 助手辅助进行恶意软件或二进制文件分析
- **智能调试助手**：结合大语言模型实现自然语言驱动的调试操作
- **批量漏洞测试**：程序化控制调试器进行自动化 fuzzing 或漏洞验证

## 4. 技术亮点
- 使用 Zig 语言编写，编译为单一可执行文件，部署简洁
- 零运行时依赖，跨平台兼容性强
- 基于 MCP 协议实现 AI 与调试器的标准化对接

- **多模态训练**：支持视觉语言模型（VLM）的微调任务

- **研究实验**：快速验证不同微调策略和模型架构的效果

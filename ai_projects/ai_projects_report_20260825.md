# GitHub 项目分析：deepseek-v4-flash-vision-video-rag

---

## 1. 中文简介

该项目是一个基于 DeepSeek 视觉大模型的视频理解与问答 Agent 技能。它能让 AI 真正"看懂"视频内容，并对视频进行提问，返回答案及对应的时间戳，同时生成可播放片段和关键帧供用户核对。

---

## 2. 核心功能

- **视频帧索引**：按时间轴抽帧并建立一次性索引，支持快速检索。
- **三层问答流程**：本地粗筛 → 视觉精排 → 深度阅读回答，提升答案准确性。
- **时间戳引用**：回答附带 `[MM:SS]` 格式时间戳，精准定位答案位置。
- **HTML 预览页自动生成**：输出自包含的 HTML 文件，内嵌可播放片段、关键帧和答案，双击浏览器即可查看。

---

## 3. 适用场景

- **视频内容检索**：快速定位视频中特定事件或信息的发生时间。
- **教学/培训视频分析**：帮助学习者精准找到关键知识点片段。
- **监控视频分析**：从长时间监控录像中快速定位目标事件。
- **视频资料整理**：为视频库建立可检索的索引和问答能力。

---

## 4. 技术亮点

- 采用 **DeepSeek V4-Flash Vision** 视觉大模型，具备较强的视频理解能力。
- 支持 **本地粗筛 + 视觉精排** 的两阶段检索策略，兼顾效率与精度。
- 输出 **自包含 HTML 预览页**，无需额外依赖即可在浏览器中直接查看结果。

- 提供 LoRA、QLoRA、P-Tuning 等多种高效微调方法
- 集成 RLHF（基于人类反馈的强化学习）训练能力
- 支持量化技术，降低显存占用，提升推理效率
- 兼容 Hugging Face Transformers 生态，开箱即用

- 需要多模态（图文）理解与生成能力的模型训练
- 企业级指令微调与对齐训练（SFT/RLHF）

Skyvern 是一款利用 AI 技术自动化浏览器工作流的开源工具。它通过结合大语言模型（LLM）与计算机视觉能力，能够像人类一样操作浏览器完成复杂的网页交互任务，无需手动编写自动化脚本。

## 2. 核心功能
- **AI 驱动的浏览器自动化**：利用大语言模型理解网页内容并自动执行操作，无需预设固定脚本
- **视觉感知能力**：通过计算机视觉技术识别页面元素，实现类似人眼的页面理解与交互
- **支持主流自动化工具**：兼容 Playwright、Puppeteer、Selenium 等浏览器自动化框架
- **RPA 工作流编排**：提供 API 接口，支持将多个浏览器操作编排为完整的工作流
- **Python 生态集成**：以 Python 为核心语言开发，便于开发者快速集成到现有系统中

## 3. 适用场景
- **企业级 RPA 自动化**：替代传统 Rule-based RPA 工具，自动化处理复杂的网页表单填写、数据抓取等重复性工作
- **跨平台工作流集成**：将浏览器操作与 Power Automate 等流程自动化工具结合，实现端到端业务流程自动化
- **AI 辅助的数据采集**：对结构不规则或动态变化的网页进行智能数据提取和信息录入
- **测试与验收场景**：自动化执行浏览器测试用例，验证网页应用的功能正确性

## 4. 技术亮点
- 将 **GPT 等大语言模型**与浏览器自动化深度结合，实现"理解-决策-执行"的闭环
- 采用 **Vision + LLM** 的双引擎架构，既懂文字也"看得懂"页面布局
- 提供标准化 **API 接口**，方便与企业现有系统集成
- 对标 Power Automate 等商业产品，但以开源形式提供，降低企业自动化成本

## 项目分析：deepseek-v4-flash-vision-video-rag

### 1. 中文简介
该项目是一个基于 DeepSeek 视觉大模型的视频理解与问答 Agent 技能，能让 AI "看懂"视频内容。用户提问后，系统会返回答案、精确到秒的时间戳，并自动生成本地可播放的视频片段和关键帧供核对。

### 2. 核心功能
- **按时间轴抽帧建索引**：一次性读取视频并建立时间轴索引
- **三阶段智能检索**：本地粗筛 → 视觉精排 → 深度阅读回答
- **精准时间戳引用**：答案附带 `[MM:SS]` 格式的时间戳定位
- **自动生成 HTML 预览页**：内嵌可播放片段、关键帧和答案，双击浏览器即可打开
- **自包含交付**：所有资源打包在一个 HTML 文件中，无需额外依赖

### 3. 适用场景
- **视频内容快速检索**：从长视频中快速定位特定片段，如会议记录、教程视频
- **在线教育/学习**：学生针对课程视频提问，直接获取答案和对应时间点
- **视频素材审核与质检**：批量查看视频关键帧，快速定位问题片段
- **内容创作者辅助**：从大量视频素材中快速提取所需片段和关键画面

### 4. 技术亮点
- 基于 DeepSeek 最新视觉大模型（deepseek-v4-flash-vision-exp），具备较强的视频理解能力
- 采用"索引+检索+精排"的分阶段处理策略，兼顾效率与准确性
- 生成的 HTML 预览页完全自包含，便于离线分享和查看
- 作为 Agent Skill 设计，可灵活集成到现有工作流中

# ONNX 项目分析

## 1. 中文简介
ONNX（Open Neural Network Exchange）是一个开放标准，旨在实现机器学习模型在不同框架之间的互操作性。它允许开发者在不同深度学习平台之间自由转换模型，打破框架壁垒，提升模型部署的灵活性。

## 2. 核心功能
- **跨框架模型转换**：支持 PyTorch、TensorFlow、Keras 等主流框架间的模型格式转换
- **统一模型表示**：提供标准化的模型定义格式，兼容多种深度学习计算图结构
- **多平台部署**：支持在 CPU、GPU、移动端等多种硬件平台上运行模型
- **生态工具链**：提供模型检查、转换、优化工具，确保模型质量与性能

## 3. 适用场景
- **模型迁移**：将训练好的模型从 PyTorch 转换为 TensorFlow 或其他框架部署
- **生产环境部署**：将模型转换为 ONNX 格式后，在高性能推理引擎（如 TensorRT、ONNX Runtime）上运行
- **移动端集成**：将深度学习模型部署到 iOS、Android 等移动设备
- **跨团队协作**：不同团队使用不同框架时，通过 ONNX 共享模型资产

## 4. 技术亮点
- **开源社区驱动**：由 Microsoft、Facebook 等科技巨头共同维护，拥有活跃的开源社区
- **广泛框架支持**：原生支持 PyTorch、TensorFlow、scikit-learn 等主流 ML 框架
- **高性能推理**：配合 ONNX Runtime 可实现高效的跨平台模型推理
- **标准化程度高**：已成为机器学习领域事实上的模型交换标准之一

## 项目分析：deepseek-v4-flash-vision-video-rag

### 1. 中文简介
该项目是一个基于 DeepSeek 视觉大模型的视频理解与问答 Agent 技能，让 AI 能够"看懂"视频内容并回答用户提问。系统会在视频时间轴上抽帧建立索引，然后对问题进行粗筛、精排和深度阅读，最终给出带时间戳的答案，并自动生成可播放片段和关键帧的 HTML 预览页供用户核对。

- **时间轴抽帧索引**：按时间顺序提取关键帧并建立索引（一次性处理）
- **多级问答流程**：本地粗筛 → 视觉精排 → 深度阅读回答
- **时间戳引用**：回答附带 [MM:SS] 格式的时间定位，精准指向答案出处
- **HTML 预览生成**：自动生成自包含的 HTML 页面，内嵌可播放片段和关键帧

### 3. 适用场景
- **视频内容检索**：快速定位视频中特定事件或信息出现的时间点
- **教学视频问答**：学生可向教学视频提问，获取精准答案和对应片段
- **会议/讲座回放**：从长时间会议视频中快速查找关键发言或演示内容
- **视频素材管理**：对视频库进行智能索引和语义化搜索

### 4. 技术亮点
- 采用"先建索引后问答"的分阶段架构，提升响应效率
- 结合本地粗筛与视觉精排，平衡准确性与计算成本
- 生成的 HTML 预览页完全自包含，无需额外依赖即可在浏览器中查看
- 支持时间戳引用机制，实现答案可追溯、可验证

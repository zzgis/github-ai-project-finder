## graph-memory-starter 项目分析

### 1. 中文简介
这是一个为 AI 助手提供知识图谱记忆的轻量级工具，通过三个 SQLite 表和一个递归查询实现持久化记忆功能，仅需一个 prompt hook 即可集成。

### 2. 核心功能
- **知识图谱存储**：使用三个 SQLite 表结构化存储 AI 助手的对话记忆和知识节点
- **递归查询能力**：通过单一递归查询实现关系图谱的遍历和记忆检索
- **Prompt 集成**：提供 prompt hook 机制，将记忆内容无缝注入对话上下文
- **轻量级架构**：纯 Python 实现，零外部依赖，开箱即用
- **持久化记忆**：支持跨会话的记忆保存与恢复，让 AI 助手具备长期记忆能力

### 3. 适用场景
- **对话式 AI 助手**：为客服、个人助理等场景提供跨会话的记忆能力
- **知识问答系统**：构建基于知识图谱的智能问答机器人
- **多轮对话应用**：需要保持上下文连续性的交互式应用
- **小型项目快速原型**：需要快速集成记忆功能的轻量级 AI 应用

### 4. 技术亮点
- **极简设计**：仅三个表 + 一个查询 + 一个 hook，架构清晰易懂
- **SQLite 驱动**：无需额外数据库服务，单文件存储便于部署
- **递归查询**：利用 SQLite 的 CTE 递归能力高效遍历知识图谱关系
- **Python 原生**：无第三方依赖，兼容性好，易于二次开发
- 链接: https://github.com/Glitch-Cat-Club/graph-memory-starter

# ONNX 项目分析

## 1. 中文简介
ONNX（Open Neural Network Exchange）是一个开放的机器学习模型互操作性标准，旨在实现不同深度学习框架之间的无缝模型迁移。该标准由Facebook和Microsoft联合发起，支持跨平台、跨框架的模型部署与交换。

## 2. 核心功能
- 提供统一的模型格式，支持PyTorch、TensorFlow、Keras等主流框架的模型导出与导入
- 实现跨平台模型部署，可在不同硬件设备（CPU、GPU、移动设备）上运行
- 支持模型转换工具链，可将模型从一种框架转换为ONNX格式后再转换到目标框架
- 提供丰富的算子库，覆盖常见深度学习网络层和运算操作

## 3. 适用场景
- 将PyTorch训练的模型部署到生产环境（如移动端或嵌入式设备）
- 在TensorFlow和PyTorch之间迁移已有模型，避免重新训练
- 利用ONNX Runtime进行高性能推理，优化模型执行效率
- 跨框架模型协作，整合不同框架训练出的组件模型

## 4. 技术亮点
- 由开源社区广泛支持，已成为机器学习生态的事实标准
- 支持动态形状和复杂控制流，兼容各种神经网络架构
- 提供优化工具（如onnx-simplifier）对模型进行剪枝、量化等性能优化
- 与主流推理引擎（TensorRT、OpenVINO、Core ML等）深度集成

# GitHub 项目分析：dance-video-to-prompt

## 1. 中文简介
该项目可将本地舞蹈短视频自动反推生成 AI 视频生成提示词。通过抽帧、清晰度分析、节奏卡点检测等技术，精准提取视频关键特征，辅助创作高质量的 AI 视频提示词。

## 2. 核心功能
- **视频抽帧处理**：自动从短视频中提取关键帧画面。
- **清晰度分析**：检测视频帧的清晰度，筛选高质量画面。
- **节奏卡点检测**：识别舞蹈视频的节奏节点，精准捕捉动作瞬间。
- **提示词自动生成**：基于视频内容反推结构化的 AI 视频生成提示词。
- **Agent Skill 集成**：支持 Agent 技能调用，实现自动化工作流。

## 3. 适用场景
- AI 视频创作者将舞蹈短视频快速转化为 Stable Diffusion 等工具的提示词。
- 舞蹈教学或内容创作者批量生成视频描述文本。
- 短视频平台运营者快速制作 AI 生成内容的参考素材。
- 视频分析与提示词工程自动化研究。

## 4. 技术亮点
- 结合**节奏卡点检测**与**抽帧技术**，精准捕捉舞蹈动作的关键瞬间。
- 支持**Agent Skill**扩展，可与其他 AI 工具链无缝集成。
- 本地化处理，保护用户视频隐私，无需上传至云端。
- 链接: https://github.com/CattleZ/dance-video-to-prompt

### 1. 中文简介
LlamaFactory 是一个统一且高效的微调框架，支持对 100 多种大语言模型（LLM）和视觉语言模型（VLM）进行微调训练，相关研究已发表于 ACL 2024。该项目旨在降低大模型微调门槛，让开发者能够以统一的接口快速适配不同架构的模型。

### 2. 核心功能
- 支持 100+ 种主流大语言模型和视觉语言模型的统一微调
- 提供 LoRA、QLoRA、全参数微调等多种高效微调策略
- 支持 RLHF（基于人类反馈的强化学习）及 DPO 等对齐训练方法
- 内置量化训练功能，降低显存占用，适配消费级显卡
- 提供 Web UI 和命令行两种交互方式，降低使用门槛

### 3. 适用场景
- 研究人员和开发者需要对多种开源大模型进行指令微调（Instruction Tuning）
- 在显存受限的消费级 GPU 上高效微调大规模语言模型
- 企业或个人希望快速将开源模型适配到特定领域任务
- 需要同时支持文本和视觉多模态模型的微调场景

### 4. 技术亮点
- 统一接口设计，一套代码即可适配数十种不同架构模型，无需逐个适配
- 支持 MoE（混合专家）架构模型的高效训练

- 项目星标数超过 7.4 万，社区活跃，文档完善，是同类工具中的热门选择
